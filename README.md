A modern, high-performance web storefront designed for **Al Hafiz Laptop**, located in Akora Khattak, KPK, Pakistan. Built using pure vanilla technology (HTML5, CSS3, and ES6+ JavaScript), this site delivers an ultra-fast, visually stunning user experience featuring glassmorphism, responsive components, dynamic product search/filtering, and direct integration with WhatsApp checkout.

---

## ✨ Features

- 🎨 **Premium Aesthetic & Micro-interactions**
  - Vibrant deep-blue tech color palette with glowing gradient backgrounds.
  - Sleek glassmorphism style cards, smooth transitions, and scale-up hover animations.
  - Fully responsive layout adapting perfectly from widescreen monitors down to smartphones.

- 🛒 **Interactive Cart Drawer & Wishlist**
  - Slide-out shopping cart drawer for a seamless, page-reload-free checkout flow.
  - Dynamic pricing aggregation, item quantity controls, and persistent badges.
  - Dynamic wishlist indicators tracking favorite laptops.

- 🎮 **Pro Gaming Neon Arena**
  - Custom RGB themed dark-mode container built specifically to highlight high-end gaming laptops (ASUS ROG/TUF, Lenovo Legion, MSI, etc.).

- 🔍 **Real-time Client-Side Search & Brand Filter**
  - Instant text searching indexing titles, processors, storage, and prices.
  - Interactive brand filter tabs (HP, Dell, Lenovo, Apple, ASUS, Acer, MSI) for easy inventory scanning.

- 💬 **WhatsApp Direct Checkout & Order Generator**
  - Order button dynamically aggregates cart item lists, quantities, and pricing.
  - Pre-fills a professional, structured WhatsApp order message template redirecting to the official store number (`+923338865194`).

- 🛠️ **Workshop Repairs & Local Services Booking**
  - Service directory describing motherboard repair, diagnostic services, battery replacements, and OS upgrades with booking request options.

## 🚀 Getting Started

### Prerequisites
You need a simple web browser to open the project. For the best developer experience, serving files via a local dev server is recommended to prevent CORS or path limitations.

### Running Locally
1. Clone the repository to your machine:
   ```bash
   git clone https://github.com/your-username/al-hafiz-laptop-store.git
   ```
2. Navigate to the project folder:
   ```bash
   cd al-hafiz-laptop-store
   ```
3. Run the development server (requires [Node.js](https://nodejs.org/)):
   ```bash
   npm run dev
   ```
   *Note: This command spins up a lightweight static file server via `npx serve`.*

4. Open `http://localhost:3000` (or the port specified in terminal) in your browser.
